What is ToolBox?

ToolBox is a self-hosted personal management hub. All your data stays on your own server — nothing is shared with third parties. It covers four main areas:

💰
Finance
Accounts, budgets, subscriptions
📈
Investments
Portfolio, research, DCF
🏋️
Fitness
Workouts, weight, plans
📝
Memos
Rich notes with categories

Finance

Accounts

Track all your bank balances in one place.

  • Add accounts by selecting a bank, type (Current / Savings / Broker), and balance
  • Supported banks: N26, Sparkasse, Trade Republic, Wise, Revolut
  • Edit or delete accounts at any time
  • View net worth history chart and take manual snapshots
  • See 6-month savings rate trend
FIRE Goal

Set your retirement target. Fill in your target yearly income, expected return rate, tax rate, yearly contribution, and current age. ToolBox calculates your required corpus, years to goal, and projected FIRE age automatically. The current corpus is pulled live from your bank balances.

Savings Goals

Create named savings goals (e.g. "Holiday fund") with a target amount and optional deadline. Contribute to them incrementally and track progress with a bar.

Budget

Plan and track spending month by month.

  • Pick any month using the date picker, or jump to the current month
  • Set a monthly plan: income categories (Salary, Bonus, Freelance, Other) and expense categories (Rent, Utilities, Groceries, Dining, etc.)
  • Add actual income and expense transactions throughout the month
  • Summary shows: planned vs actual, savings amount, savings rate %, budget adherence %
  • Import a bank CSV (N26, Sparkasse, or auto-detect) to bulk-load transactions
  • Set up recurring transactions (weekly / monthly / yearly) for predictable income or expenses
  • Compare multiple months with the budget comparison chart
Subscriptions

Keep track of every recurring service you pay for.

  • Add subscriptions with name, provider, amount, billing cycle, and next billing date
  • KPIs: total monthly cost, total annual cost, active count
  • Mark subscriptions as inactive to exclude them from totals without deleting
  • Enable push notifications to get reminders 3 days before a renewal

Investments

Portfolio

Track stock holdings, dividends, and alerts.

  • Holdings — add stocks with symbol, quantity, and buy price. Prices update automatically. Export to CSV anytime.
  • Watchlist — track stocks you don't own yet. Set an initial price to see how they've moved.
  • Dividends — log dividend payments with amount, date, and frequency. See total received and annual projection.
  • Price Alerts — set ABOVE/BELOW price targets. Get a push notification when triggered.
  • Capital Gains — see realised and unrealised gains broken down by holding.
  • Allocation — pie chart of your portfolio split. Set target % per stock and see rebalancing suggestions.
History

Advanced candlestick chart with full technical analysis for any holding.

  • Select symbol and interval (1m to 1w) and time range (1D to ALL)
  • Toggle indicators: SMA, EMA, Bollinger Bands, RSI, MACD, Volume
  • Performance metrics: CAGR, Sharpe ratio, max drawdown, alpha, beta
  • Export chart as PNG
Research

AI-assisted research report for your entire portfolio.

  • Click Generate Research Report to analyse all holdings (news, technicals, fundamentals)
  • Reload the latest saved report instantly with Load Latest Report
  • Each holding gets a sentiment rating; overall portfolio sentiment shown at the top
Fundamentals

Deep-dive into any company's financial health.

  • Search by symbol or name (autocomplete). Or pick directly from your portfolio.
  • Key ratios: P/E, EPS, ROE, Dividend Yield, and more
  • Charts: Revenue history, EPS beat/miss, Free Cash Flow, Margin trends
  • Historical price chart with SMA/EMA/Bollinger toggle
DCF

Discounted Cash Flow valuation tool.

  • Enter a symbol and click Load Defaults to pre-fill from fundamentals data
  • Adjust: Initial FCF, growth rate, WACC, terminal growth rate, projection years, shares outstanding, current price
  • Result: intrinsic value per share, margin of safety, verdict (Undervalued / Fair / Overvalued)
  • Sensitivity analysis table showing how value changes with different assumptions
Screener

Filter and compare stocks by fundamental criteria.

  • Add any stock symbol to the screener pool
  • Filter by: Sector, P/E range, Market Cap, Dividend Yield, ROE, Debt/Equity
  • Sort by: Market Cap, P/E, Dividend Yield, ROE, Profit Margin
  • Click any row to view the full fundamentals for that stock

Fitness

Log workouts, track weight, and build structured training plans.

Logging

  • Log a workout: date, type (Push/Pull/Legs/Cardio/Full Body/Core/Rest), duration, calories, notes
  • Log weight daily with optional notes
  • Weight chart shows trend over time
  • Today's banner shows your scheduled workout from your active plan

Plans & Templates

  • Create templates — a named workout with type, estimated duration, and exercise list
  • Create plans — assign templates to days of the week (e.g. Push on Mon/Thu, Pull on Tue/Fri)
  • Set one plan as Active — it drives the weekly schedule grid and Today's banner

Stats & Analytics

  • KPIs: current streak, longest streak, workouts this week, total workouts
  • Workouts by type pie chart
  • Weekly volume chart
  • Consistency score: % of weeks in the last 12 where you hit 3+ workouts

Memos

Rich-text notes with categories, pinning, and optional image attachments.

  • Write with the full Quill editor: bold, italic, headers, lists, code blocks, links
  • Four categories: Personal Work Ideas Journal
  • Pin important memos — they always appear at the top
  • Attach an image to any memo
  • Filter by category using the tabs at the top
  • Copy memo text to clipboard with one click
  • Paginated list — choose 10 / 20 / 30 / 50 per page

System Admin only

Live server health monitoring. Refreshes every ~900ms.

  • CPU usage, memory (used / total), disk, swap, and network stats
  • JVM metrics: heap, non-heap, uptime
  • Enable browser push notifications to get alerts when CPU, Memory, or Disk exceeds 90% (5-minute cooldown between alerts)
  • Test notifications with the Test button once subscribed

Password Reset Flow

  1. Admin clicks Reset PW on the user's row
  2. A unique link is generated (valid 24 hours, single use)
  3. Admin copies the link and sends it to the user (WhatsApp, email, Slack, etc.)
  4. User opens the link, enters a new password, and is redirected to login
